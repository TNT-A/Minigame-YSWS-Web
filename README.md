# Minigame YSWS Website
Made in Visual Studio, Pixel art in Aseprite!

**Project Details:**

This is the website I made for my Hack Club YSWS program, Minigame! This was my first web project in over a year, so it was fun relearning the process. Made using basic HTML, CSS, & JavaScript. This GitHub has the files and sprites for the website.



**Site Description:**

For context, Minigame was a program developed with Hack Club, and the point of the program was to inspire other teens to make small, simple games, then upload them to be added to a large project gallery. The site has one page dedicated to introducing the event, one page dedicated to my example project and basic tutorial, one page dedicated to collecting submissions, and one page dedicated to the project gallery. The website originally only had the intro, tutorial, and submission page, but following the event I added a gallery to showcase every project submitted in the event. 

Check it out here: https://tnt-a.github.io/Minigame-YSWS-Web/
